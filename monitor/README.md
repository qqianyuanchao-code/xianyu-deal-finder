# 闲鱼搜索提醒（实验版）

此脚本在电脑浏览器中检查打开的闲鱼搜索页。登录在闲鱼页面自行完成；脚本不读取或上传 Cookie。

1. 在电脑浏览器安装用户脚本管理器（如 Tampermonkey）。
2. 在管理器中新建脚本，将 `monitor/goofish-watch.user.js` 的内容复制进去并保存。
3. 打开闲鱼网页版，登录并搜索关键词。
4. 在搜索页右下角设置最高价与检查间隔，点击“开启提醒”，并允许浏览器通知。

首次成功检查建立基线，不提醒已有商品；后续检测新出现商品，符合价格条件时发浏览器通知。若设置最高价，无法识别价格的商品不会提醒。若网页无法识别商品，脚本会停止并提示检查登录、验证码或网页变化。每个关键词独立保存状态。

请保持搜索页面、浏览器和电脑运行；关闭页面、浏览器、电脑或电脑休眠后不会检查。此功能依赖网页展示的商品及结构，不保证发现所有新商品，不检测售出或指定商品降价；可能受闲鱼网页变化、登录状态和浏览器通知设置影响。不会自动联系卖家或下单。
